# stockflow-backend
Proyecto StockFlow Backend para mostrar habilidades de profracion.
Informacion:
Proyecto creado en Java 17 con maven, con el framework Sprign Boot version 3.5.15 con empaquetado de tipo war.
Tareas realizadas en el proyecto:
1. configuracion de base de datos, creacion de tablas y poblado de las mismas.
2. Creacion de la estructura del microservicio -Controller->Servicio->Repositorio->Base de datos.
3. Creacion de Dtos y Entidades
4. Creacion de Respositorios
5. Creacion de Mapper para pasar de Dto a entidades y vicersa cuando la funcionalidad no amerita.
6. Creacion de interfaces
7. Creacion de capa de servicio para agregar la logica de negocio.
8. Creacion de controladores para exponer endpoints.
9. Creacion de querys personalizados donde la funcionalidad lo ameritaba.
10. Configuracion de healt,metrics, info y healt personalizado.
11. Implementacion de resilience4j
12. Creacion de Excepciones
13. Manejo de respuestas de error con ControllerAdvice
14. Configuracion de Hikari.
15. Creacion de los 5 endpoins solicitados.
